University Management System Using Java

Project Overview

The University Management System is a Java-based project that demonstrates Object-Oriented Programming concepts using inheritance.

This project manages basic information related to students, employees, professors, and staff.

Objectives

- To understand inheritance in Java.
- To display student information.
- To calculate student percentage.
- To calculate employee salary.
- To calculate professor and staff salary.

Technologies Used

- Programming Language: Java
- IDE: VS Code
- Concept: Object-Oriented Programming (OOP)

OOP Concepts Used

1. Inheritance
2. Multilevel Inheritance
3. Hierarchical Inheritance
4. Classes and Objects
5. Methods

Project Classes

- Person: Stores name and ID.
- Student: Stores branch, semester and marks; calculates percentage.
- Employee: Calculates salary using HRA and DA.
- Professor: Calculates salary with research allowance.
- Staff: Calculates salary with overtime hours.
- UniversitySystem: Main class to execute the program.

How to Run

1. Install Java JDK.
2. Open the project in VS Code.
3. Open Terminal.
4. Compile: "javac UniversitySystem.java"
5. Run: "java UniversitySystem"
